Bonuscard Connector

Connect Odoo POS to the Bonuscard API with Basic-auth credentials, customer lookup, purchase validation, and automatic discount application.

Highlights

  • Per-company API connection records with diagnostics and Test Connection
  • Basic-auth request service with Bonuscard error handling and HTTP retry
  • Automatic customer lookup in POS: searches by phone, email, and name when a customer is selected
  • Bonuscard status fields on partner form (Linked, Not Found, Multiple Matches, Error)
  • Smart button and manual check/reset controls on the partner form
  • Status badges in the POS partner selection screen
  • Register customers from the partner form or POS partner list when not found in Bonuscard
  • ValidatePurchase, FinalizePurchase, and CancelPurchase lifecycle with automatic POS discount application
